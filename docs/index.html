Your ServiceNow,
as MCP tools for Claude.

A local gateway that wraps ServiceNow REST APIs as MCP tools. Point it at your instance, pick or build tools in a web UI, and connect Claude Desktop, Claude Code or any MCP client.

$npx servicenow-mcp-gateway

Needs Node 20+. Opens the UI at localhost:3001. Settings live in ~/.servicenow-mcp-gateway.

01

Servers and tools

Each MCP server is a group of tools on its own port. Every tool is a ServiceNow API with a name, description and parameters, which is what the model sees.

  1. 1
    One server per jobIncidents, changes, CMDB, business rules, script includes, client scripts, problems. All start automatically, each on its own port.
  2. 2
    Endpoint and configCopy the MCP URL, or open Config snippet for ready-to-paste client config.
  3. 3
    Who ServiceNow seesRun tools as a service account, or have each user sign in with OAuth. Toggle MCP Apps (interactive UIs) per server.
  4. 4
    ToolsWrap the Table API, a Scripted REST endpoint or a built-in code handler. Edit and Claude sees the change on its next call.
  5. 5
    Add your ownNew tools and new servers in a couple of clicks. Writes are rate-limited and audit-logged.
  6. 6
    Instance & OAuthConnect your instance and manage OAuth sign-in from the sidebar.
02

Apps inside the chat

MCP Apps show a real form, table or approval card in Claude instead of plain text. Build one without code, or attach your own HTML.

  1. 1
    Pick a typeForm, table / chart, approval cards, or your own HTML file.
  2. 2
    Describe itWrite what you want and copy a ready prompt for Claude. It writes the spec for you.
  3. 3
    Spec, not codeA short JSON spec, checked against this server's tools before it saves.
  4. 4
    Live previewReads hit your instance, writes are a dry run, so you can test safely.
  5. 5
    Opened by a toolClaude calls this tool to show the app. Change forms and approval inboxes ship built in.
03

Connect a client

Every server gives you copy-paste config for Claude Desktop and Claude Code. Any other MCP client just needs the URL.

  1. 1
    Choose sign-inService account (simplest), OAuth sign-in through the browser, or per-user login for demos.
  2. 2
    Claude DesktopPaste into claude_desktop_config.json. It bridges through mcp-remote.
  3. 3
    Claude CodeOne claude mcp add command…
  4. 4
    …or a project fileCommit .mcp.json so the whole team gets the server.

Get started

Pick whichever fits. Or hand the agent skill to Claude and let it do the setup.

Run with npx

Nothing to install. Pass your instance in env vars, or enter it later in the UI.

SN_INSTANCE_URL=https://devXXXXX.service-now.com \
SN_USERNAME=... SN_PASSWORD=... \
npx servicenow-mcp-gateway

Install globally

Keep a .env in ~/.servicenow-mcp-gateway and run it any time.

npm install -g servicenow-mcp-gateway
servicenow-mcp-gateway

From source

To change the code or contribute.

git clone https://github.com/yvain13/Servicenow-mcp-gateway.git
cd Servicenow-mcp-gateway
npm install && npm run dev

Let your agent set it up

Give this skill to Claude Code (or any coding agent). It installs and starts the gateway, connects your instance, registers the MCP servers with your client, and hands you back their names and URLs.

  1. Install the skill. For Claude Code, save it as a personal skill: 
    mkdir -p ~/.claude/skills/servicenow-mcp-gateway && curl -fsSL https://yvain13.github.io/Servicenow-mcp-gateway/SKILL.md -o ~/.claude/skills/servicenow-mcp-gateway/SKILL.md
  2. Or just paste it. Copy the file on the right and paste it into any agent's chat.
  3. Ask. “Set up the ServiceNow MCP gateway for my instance.”
  4. Answer one question. The agent asks for your instance URL and login, then does the rest.
  5. Done. You get the UI link and a table of MCP servers, already added to Claude.
